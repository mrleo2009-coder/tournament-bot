# 🏆 Telegram-бот турнирной платформы

Бот для управления турнирами с регистрацией участников, профилем игроков и техподдержкой.

## 📋 Функции

### Для игроков:
- 👤 **Профиль** — ID, ник, количество сыгранных турниров, список регистраций
- 🏆 **Турниры** — просмотр турниров, регистрация/отмена регистрации
- 📜 **Правила** — свод правил платформы
- 🛠 **Техподдержка** — отправка обращений администратору

### Для админов:
- ➕ **Создание турниров** — пошаговое создание через FSM
- 💬 **Ответы на обращения** — ответ через inline-кнопку
